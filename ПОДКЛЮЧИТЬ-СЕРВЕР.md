# Как подключить сервер-посредник (бесплатно, ~10 минут)

Зачем: твой ключ Gemini будет лежать на сервере Cloudflare, а не в приложении. Друзья получают
только **код доступа**: с ним всё работает, а ключа они никогда не видят. Не нравится кто-то —
меняешь код, и доступ закрыт у всех.

Бесплатный тариф Cloudflare Workers: 100 000 запросов в сутки, карта не нужна.

## Шаг 1. Создать воркер
1. Зайди на https://dash.cloudflare.com и зарегистрируйся (почта + пароль, бесплатно).
2. Слева выбери **Workers & Pages** → **Create** → **Create Worker** (или «Start with Hello World»).
3. Имя: `emodji-proxy` → **Deploy**.
4. Нажми **Edit code**, удали весь код слева и вставь весь файл `worker/worker.js` из этой папки.
5. Нажми **Deploy** (справа вверху).

## Шаг 2. Положить ключ и код в секреты
1. В воркере открой **Settings** → **Variables and Secrets** → **Add**.
2. Тип **Secret**, имя `GEMINI_API_KEY`, значение — твой ключ Gemini → **Deploy**.
3. Ещё один секрет: имя `ACCESS_CODE`, значение — придуманный тобой код (например `kot-1234-pizza`).
   Его будешь давать друзьям.

Секреты после сохранения нельзя посмотреть, только заменить. Так и задумано.

## Шаг 3. Дать адрес приложению
Адрес воркера выглядит так: `https://emodji-proxy.dkhovz.workers.dev` (уже создан и вписан в приложение) (виден на главной странице воркера).
Пришли мне этот адрес, я впишу его в приложение, и друзьям останется вводить только код.
(Или каждый вводит его сам в ⚙ → «Адрес сервера».)

## Шаг 4. Залить новую версию на GitHub
Залей `index.html`, `app.js` и (по желанию) папку `worker` и этот файл.

## Как пользоваться
- **Друг:** открывает ссылку, в ⚙ вводит код доступа, готово.
- **Ты:** можешь по-прежнему вводить свой ключ напрямую (тогда сервер не нужен) или тоже ходить через сервер по коду.
- **Отключить всех:** Cloudflare → воркер → Settings → Variables and Secrets → поменять `ACCESS_CODE`.

## Защита, которая уже встроена в воркер
- Принимает запросы только с твоего сайта `dimakhovz.github.io` (и `localhost:8765` для проверок).
- Без правильного кода отвечает «нельзя». Если код не задан вообще, не пускает никого.
- Разрешены только запросы к моделям `gemini-*`, остальные адреса закрыты.
- Не больше 40 запросов в минуту с одного адреса и ограничение размера запроса.

## Лимит на расходы (сделай обязательно)
В Google AI Studio / Cloud Console поставь для ключа дневную квоту запросов или бюджет с оповещением,
чтобы даже при неудачной раздаче кода списание было ограниченным.
